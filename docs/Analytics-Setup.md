# 📊 Настройка аналитики для Viktorija Autokool

## 🎯 Обзор

В проект интегрированы два основных инструмента аналитики:
- **Google Analytics 4 (GA4)** - для отслеживания трафика и конверсий
- **Inspectlet** - для записи сессий пользователей и тепловых карт

## 🔧 Настройка Google Analytics 4

### 1. Создание аккаунта GA4

1. Перейдите на [Google Analytics](https://analytics.google.com/)
2. Создайте новый аккаунт или используйте существующий
3. Создайте новое свойство для сайта автошколы
4. Выберите "Веб" как платформу
5. Укажите URL сайта: `https://viktorijaautokool.ee`
6. Скопируйте **Measurement ID** (формат: G-XXXXXXXXXX)

### 2. Настройка в проекте

1. Создайте файл `.env` в корне проекта
2. Добавьте ваш Measurement ID:
```env
REACT_APP_GA_MEASUREMENT_ID=G-ВАШИ_ЦИФРЫ_ЗДЕСЬ
```

### 3. Настройка целей и конверсий

В GA4 настройте следующие события как конверсии:

#### Основные конверсии:
- `form_submit` - Отправка формы заявки
- `phone_click` - Клик по номеру телефона
- `newsletter_subscribe` - Подписка на рассылку
- `begin_checkout` - Начало записи на курс
- `purchase` - Завершение записи на курс

#### Дополнительные события:
- `whatsapp_click` - Клик по WhatsApp
- `telegram_click` - Клик по Telegram
- `email_click` - Клик по email
- `social_click` - Клики по соцсетям

### 4. Настройка Google Ads (опционально)

Если планируете рекламу в Google Ads:
1. Свяжите GA4 с Google Ads
2. Настройте импорт конверсий
3. Обновите ID конверсий в `src/config/analytics.ts`

## 🎥 Настройка Inspectlet

### 1. Создание аккаунта

1. Перейдите на [Inspectlet.com](https://www.inspectlet.com/)
2. Зарегистрируйтесь или войдите в аккаунт
3. Создайте новый сайт
4. Укажите домен: `viktorijaautokool.ee`
5. Скопируйте **Site ID** (числовой ID)

### 2. Настройка в проекте

Добавьте Site ID в файл `.env`:
```env
REACT_APP_INSPECTLET_ID=ВАШИ_ЦИФРЫ_ЗДЕСЬ
```

### 3. Настройка записи сессий

В панели Inspectlet настройте:
- **Запись сессий**: включить для всех посетителей
- **Тепловые карты**: включить для ключевых страниц
- **Фильтры**: исключить внутренний трафик
- **Приватность**: замаскировать чувствительные данные

## 🔒 Конфиденциальность и GDPR

### Настройки конфиденциальности

Аналитика настроена с учетом требований GDPR:
- `anonymize_ip: true` - анонимизация IP-адресов
- `allow_google_signals: false` - отключение рекламных сигналов
- `allow_ad_personalization_signals: false` - отключение персонализации

### Cookie Consent (будущее развитие)

Для полного соответствия GDPR рекомендуется добавить:
- Cookie banner с согласием пользователя
- Возможность отзыва согласия
- Политику конфиденциальности

## 🚀 Запуск аналитики

### В разработке:
```bash
# Включить аналитику в development
REACT_APP_ENABLE_ANALYTICS=true npm start
```

### В продакшене:
Аналитика автоматически включается в production сборке.

## 🔧 Техническая информация

### Файлы аналитики:
- `src/components/analytics/GoogleAnalytics.tsx` - компонент GA4
- `src/components/analytics/Inspectlet.tsx` - компонент Inspectlet
- `src/components/analytics/Analytics.tsx` - общий компонент
- `src/config/analytics.ts` - конфигурация

### Функции отслеживания:
```typescript
// Google Analytics
trackEvent('event_name', { parameter: 'value' });
trackPageView('/page-url', 'Page Title');
trackConversion('conversion_id', 100, 'EUR');

// Inspectlet
inspectletTrack('event_name', { property: 'value' });
inspectletIdentify('user_id', { name: 'User Name' });
inspectletTagSession(['tag1', 'tag2']);
```

## 📞 Поддержка

При возникновении вопросов по настройке аналитики:
1. Проверьте правильность ID в файле `.env`
2. Убедитесь что аналитика включена в настройках
3. Проверьте консоль браузера на наличие ошибок
4. Используйте расширения браузера для отладки GA4

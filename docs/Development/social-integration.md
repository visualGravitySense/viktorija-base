На сайте автошколы иконки социальных сетей можно разместить в нескольких стратегически важных местах:

**Основные локации:**

**Хедер (шапка сайта)** - в правом верхнем углу рядом с контактной информацией. Здесь они всегда видны и легко accessible.

**Футер** - классическое место для социальных иконок. Можно сделать отдельный блок "Мы в социальных сетях" с иконками и краткими описаниями.

**Контактная страница** - логично разместить рядом с другими способами связи (телефон, email, адрес).

**Страница "О нас"** - поможет создать доверие и показать активность школы в соцсетях.

**Дополнительные места:**

**Сайдбар** - если используется боковая панель, можно добавить компактный блок с иконками.

**Страница отзывов** - рядом с отзывами учеников, чтобы пользователи могли перейти и посмотреть больше отзывов в соцсетях.

**Страница курсов** - в конце описания курсов можно добавить призыв "Следите за новостями в наших соцсетях".

**Принципы размещения:**
- Иконки должны быть узнаваемыми и достаточно крупными (минимум 24x24px)
- Использовать контрастные цвета для лучшей видимости
- Добавлять hover-эффекты для улучшения интерактивности
- Группировать логически связанные элементы
- Не перегружать страницу - выбрать 2-3 основных места размещения

Для автошколы особенно важны Instagram (фото процесса обучения), VK (популярна в России), YouTube (видео-уроки) и Telegram (быстрая связь с учениками).

Рассмотрю основные варианты экспорта отзывов из социальных сетей на сайт автошколы:

## 📋 Планы реализации

### **1. Автоматический импорт (Технически сложный)**
- **API интеграция** - подключение к официальным API социальных сетей
- **Веб-скрапинг** - автоматический сбор данных (может нарушать ToS)
- **RSS/JSON фиды** - если доступны от платформ

### **2. Полуавтоматический (Рекомендуемый)**
- **Embed-коды** от соцсетей (виджеты ВКонтакте, Facebook)
- **Копирование контента** с указанием источника
- **Скриншоты + ссылки** на оригинальные посты

### **3. Ручной импорт (Простой)**
- **CMS с формами** для добавления отзывов администратором
- **База данных** с полями: автор, текст, соцсеть, дата, рейтинг

## 🔧 Практические варианты экспорта

- **Instagram Basic Display API** (требует регистрации приложения)
- **Embed посты** через официальные embed-коды
- **Сторонние сервисы**: Juicer, Taggbox, Curator

const request = {

- **Виджет карты** с отображением отзывов
